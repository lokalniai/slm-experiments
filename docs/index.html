how it was run

  • Models. Instruction-tuned BF16 checkpoints, served with vLLM 0.31, greedy decoding, the checkpoint's own chat template with enable_thinking=False, and its native tool-call parser.
  • Prompts. Every input is fully in the test language; tool descriptions and JSON schemas stay in English. The Czech json-mode set and the Czech summarization prompt are Kimi K3 translations; everything else is human-made or human-checked Czech.
  • Judge. Summaries only: Kimi K3 (e-INFRA CZ), reasoning effort high, one judge, listwise with hidden and shuffled system names.
BenchMAX Nexus (318 queries per language, 2–12 tools in context). A call counts when the function and every argument match exactly, with defaults filled in, as in BenchMAX. Tool descriptions stay in English. Each model uses its native tool format; tiny-aya, whose template has no tools, gets BenchMAX's JSON tool prompt.
